# 30_画面詳細設計書

## 1. 概要

本書は、`docs/20_基本設計/21_画面基本設計書.md`に定めた各画面について、画面を構成する項目の一つひとつ（部品の種類、入力できる文字数、初期値、表示する値の取得元、入力した値の設定先）と、操作に対する処理（入力チェック、呼び出すAPI、結果の表示）を定義する詳細設計書である。本書をもとに画面を実装できることを目的とする。

- 画面イメージは`docs/20_基本設計/21_画面基本設計書.md`と同じものを掲載する。イメージ上の丸数字（①②…）が、本書の「項目定義」のNoに対応する。
- APIの入出力項目の定義は`docs/30_詳細設計/31_API詳細設計書.md`、テーブル・カラムの定義は`docs/20_基本設計/22_テーブル定義書.md`、エラーのメッセージは`docs/30_詳細設計/33_共通詳細設計書.md`に定める。

## 2. 記載ルール

### 2.1 項目定義の列

| 列 | 記載する内容 |
|---|---|
| No | 画面イメージ上の丸数字 |
| 項目名 | 項目の名称 |
| 部品 | 画面部品の種類（2.2） |
| 入出力 | 入力：利用者が値を入力・選択する項目／表示：値を表示するだけの項目／-：ボタン等 |
| 必須 | ○：入力が必須／-：任意、または入力項目でない |
| 桁数・形式 | 入力できる最大文字数・値の範囲・形式。表示項目では、表示する値の最大文字数・書式 |
| 初期値 | 画面を表示した時点の値・状態 |
| 取得元・設定先 | 表示する値をどこから取得するか、入力した値をどこへ設定するか（2.3） |
| 表示条件・備考 | 表示・非表示や押下可否の条件、補足 |

### 2.2 部品の種類

| 部品 | 説明 |
|---|---|
| テキスト | 文字を表示するだけの部品（ラベル） |
| リンク | 押下すると他の画面へ遷移する文字 |
| 画像 | 画像を表示する部品 |
| テキストボックス | 1行の文字を入力する部品 |
| 複数行テキスト | 複数行の文字を入力する部品 |
| パスワード入力欄 | 入力した文字を伏せて表示するテキストボックス |
| 数値入力欄 | 数値のみを入力する部品 |
| 日付入力欄／日時入力欄 | 日付、または日付と時刻を入力する部品 |
| プルダウン | 選択肢から1つを選ぶ部品 |
| 切替ボタン | 表示内容を切り替えるボタン（タブ） |
| ボタン | 押下すると処理を実行する部品 |

### 2.3 取得元・設定先の書き方

| 書き方 | 意味 |
|---|---|
| AP-021 `name` ← `events.name` | APIの応答の項目を表示する。その値はデータベースの該当カラムに由来する |
| AP-030 `extraAnswer` → `applications.extra_answer` | 入力した値をAPIのリクエストの項目に設定する。その値はデータベースの該当カラムに保存される |
| 計算値（…） | データベースのカラムをそのまま表示するのではなく、括弧内の方法で算出した値 |
| 固定の文言 | 画面に直接定義した文言。データベース・APIからは取得しない |
| 固定の選択肢：… | プルダウンの選択肢を画面に直接定義する。データベース・APIからは取得しない |
| 選択肢：AP-021 `ticketTypes[]` ← `ticket_types` | プルダウンの選択肢をAPIの応答から作る。その値はデータベースの該当テーブルに由来する |
| 画面内の…にのみ使用 | APIには送らず、画面の中だけで使う値 |

### 2.4 イベント処理の列

| 列 | 記載する内容 |
|---|---|
| 契機 | 処理が始まるきっかけ（画面の表示、ボタンの押下等）。丸数字は項目定義のNo |
| 画面側のチェック | APIを呼び出す前に画面で行う入力チェック・確認。違反した場合はAPIを呼び出さない |
| 呼び出すAPI | 呼び出すAPIのID（`docs/20_基本設計/23_API基本設計書.md`） |
| 成功時 | APIが成功した場合の画面の動作 |
| 失敗時 | APIがエラーを返した場合の画面の動作 |

## 3. 全画面に共通する仕様

| 項目 | 仕様 |
|---|---|
| 共通ナビゲーション | ログイン中の全画面の上部に表示する。一般利用者には「イベント一覧（SC-020）／イベント検索（SC-021）／マイページ（SC-030）／パスワード変更（SC-011）／ログアウト」、管理者には「ダッシュボード（SC-110）／イベント管理（SC-120）／申込状況・実績（SC-130）／利用者管理（SC-140）／コメント管理（SC-150）／パスワード変更（SC-011）／ログアウト」を表示する。表示の切り替えは、ログイン時に取得した利用者区分のコード（`roleCode`）で判定する |
| ログアウト | 画面が保持している利用者ID・利用者区分を消去し、SC-010へ遷移する。APIは呼び出さない |
| 日時の表示 | `yyyy/MM/dd HH:mm`形式（日本時間）で表示する |
| 区分値の表示 | 利用者区分・申込状況は、APIが返す表示名（`roleName`・`statusName`）をそのまま表示する。表示・非表示の切り替え等の判定にはコード（`roleCode`・`statusCode`）を用いる |
| 入力エラーの表示 | APIが項目ごとのエラー（`errors[]`）を返した場合、該当する入力項目の下に赤字で表示する。該当する項目が画面に無い場合は、メッセージ表示欄にまとめて表示する |
| その他のエラーの表示 | APIが返したメッセージ（`message`）を、メッセージ表示欄にそのまま表示する。画面側で別の文言に言い換えない |
| 認証エラー（401）の場合 | ログイン状態が無効になった（退会済み、利用者が存在しない等）ものとして、画面が保持している利用者ID・利用者区分を消去し、SC-010へ遷移する。SC-010でのログイン失敗（AP-010の401）は対象外とし、SC-010のメッセージ表示欄に表示する |
| 通信できない場合 | 「サーバーに接続できません。バックエンドが起動しているか確認してください。」と表示する |
| 確認ダイアログ | 「確認ダイアログで実行を確認する」とある操作は、実行してよいかを尋ねるダイアログを表示し、利用者が承認した場合のみAPIを呼び出す |
| 最大文字数 | 最大文字数を定めた入力項目は、画面上でもその文字数を超えて入力できないようにする |
| 未ログイン・権限なしでのアクセス | 未ログインでログインが必要な画面を開いた場合はSC-010へ、一般利用者が管理者向けの画面を開いた場合はSC-020へ遷移させる（`docs/20_基本設計/20_機能設計書.md`4.3） |
