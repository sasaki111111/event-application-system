# 06_設計確定時の確認事項

## 1. 本書の位置づけ

`docs/01`〜`05`は、今後の開発における正式な要件・仕様の基準として作成した文書である。本書は、それらの文書を正式な基準として確定させるにあたり、関係者間の意思決定が必要な事項を記録し、決定後は該当する設計書へ反映するための文書である。

方針が確定した事項は「2. 確定した事項」に反映先とあわせて記録し、`docs/01`〜`05`の本文を更新する。未確定の事項は「3. 未確定事項」に記録する。
