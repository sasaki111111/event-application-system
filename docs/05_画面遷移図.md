# 05_画面遷移図

## 1. 概要

本書は、利用者がイベント申込システムをどのような順序で利用するかを表す画面遷移図である。画面の詳細は`docs/04_画面設計書.md`を参照。

## 2. 画面遷移の制御方針

- ログイン画面（SC-01）を除く全ての画面は、ログイン状態でなければ利用できず、未ログインの場合はログイン画面へ案内する。
- 管理者向け画面（SC-07〜SC-13）は、管理者としてログインしている場合にのみ利用でき、一般利用者がアクセスした場合はイベント一覧画面（SC-02）へ案内する。
- 定義されていないURLへアクセスした場合は、404画面（SC-14）を表示する。

## 3. 全体画面遷移図

```mermaid
flowchart TD
    Start(["未ログイン状態でのアクセス"]) -->|ログインへ案内| Login["SC-01<br/>ログイン"]

    Login -->|"ログイン成功（管理者）"| AdminDash["SC-07<br/>管理者ダッシュボード"]
    Login -->|"ログイン成功（一般利用者）"| EvList["SC-02<br/>イベント一覧"]
    Login -->|"新規登録成功"| EvList

    EvList <-->|画面切替| EvSearch["SC-03<br/>イベント検索"]
    EvList <-->|画面切替| My["SC-06<br/>マイページ"]
    EvSearch -->|イベント選択| EvDetail["SC-04<br/>イベント詳細・申込"]
    EvList -->|イベント選択| EvDetail
    EvDetail -->|戻る| EvList
    EvDetail -->|"戻る（検索経由の場合）"| EvSearch
    EvDetail -->|申込成功| Done["SC-05<br/>申込完了"]
    EvList -->|申込成功| Done
    Done -->|イベント一覧へ| EvList
    My -->|イベント選択| EvDetail

    EvList -.->|共通ナビゲーション| My
    My -.->|共通ナビゲーション| EvList

    AdminDash -.->|共通ナビゲーション| AdmList["SC-08<br/>イベント管理"]
    AdminDash -.->|共通ナビゲーション| AdmReport["SC-12<br/>申込状況・実績"]
    AdminDash -.->|共通ナビゲーション| AdmUsers["SC-13<br/>利用者管理"]
    AdmList -.->|共通ナビゲーション| AdminDash
    AdmList -->|新規登録| AdmNew["SC-09<br/>イベント登録"]
    AdmList -->|イベント選択| AdmEdit["SC-09<br/>イベント編集"]
    AdmList -->|削除済みイベント| AdmDeleted["SC-10<br/>削除済みイベント"]
    AdmList -->|当日受付| AdmCheckin["SC-11<br/>当日受付"]
    AdmNew -->|保存成功| AdmList
    AdmEdit -->|保存成功| AdmList
    AdmDeleted -->|イベント管理に戻る| AdmList
    AdmCheckin -->|イベント管理に戻る| AdmList

    EvList -->|ログアウト| Login
    My -->|ログアウト| Login
    AdminDash -->|ログアウト| Login

    AnyURL(["定義されていないURL"]) --> NotFound["SC-14<br/>404"]
    NotFound -->|イベント一覧に戻る| EvList
```

図中の実線は画面上の操作による遷移、点線は共通ナビゲーションからの遷移（どの画面からでも選択可能）を表す。「ログアウト」は共通ナビゲーションから全てのログイン中画面で行える（図では代表画面のみ記載）。

## 4. ログイン状態によるアクセス制御

```mermaid
flowchart LR
    U["未ログインで保護された画面へアクセス"] --> L["SC-01 ログイン画面へ案内"]
    G["一般利用者が管理者向け画面へアクセス"] --> E["SC-02 イベント一覧へ案内"]
```

## 5. イベント詳細画面の「戻る」導線

イベント詳細画面（SC-04）は、遷移元の画面に応じて「戻る」導線の遷移先を切り替える。

```mermaid
flowchart TD
    A["SC-04 イベント詳細へ遷移"] --> B{"イベント検索画面から<br/>遷移してきたか"}
    B -->|Yes| C["戻る導線：SC-03 イベント検索"]
    B -->|No| D["戻る導線：SC-02 イベント一覧（既定）"]
```

## 6. 申込完了画面への遷移

申込完了画面（SC-05）は、イベント一覧（SC-02）またはイベント詳細（SC-04）での申込成功に伴う遷移によってのみ、申込結果を表示できる画面とする。この遷移を経ずに本画面へ直接アクセスした場合は、`docs/04_画面設計書.md`SC-05に定める代替表示を行う。
