## 1. ログイン・会員登録（SC-01）

- [ ] メールアドレスでログイン（一般：`general@example.com`）→イベント一覧へ遷移
- [ ] メールアドレスでログイン（管理者：`admin@example.com`）→ダッシュボードへ遷移
- [ ] 未登録メールアドレスでログイン→「そのメールアドレスは登録されていません。」
- [ ] 新規会員登録（名前・メールアドレスのみ）→自動的に一般ユーザーとしてログインされる
- [ ] 登録済みのメールアドレスで再登録→「このメールアドレスは既に登録されています」
- [ ] 未入力のまま登録→各項目に「〜を入力してください」等が表示される
- [ ] ログアウト→ログイン画面に戻る
- [ ] 未ログイン状態で保護ページ（例：`/events`）に直接アクセス→ログイン画面にリダイレクトされる

## 2. 一般ユーザー機能

### イベント一覧（SC-02）

- [ ] サンプルイベント50件がカード表示される
- [ ] 受付中／受付終了のバッジが正しく表示される
- [ ] カードの「▼ 詳細を見る」で詳細（定員・残り枠・申込締切・説明）が展開表示される
- [ ] 展開中、同じ行の他のカードの高さが変わらず、下の行に浮かんで重なる
- [ ] 展開部分の「申し込む」→申込完了画面に遷移し、ステータスが「受付済」になっている
- [ ] イベント名が長い場合、カードのタイトルが1行に収まり末尾が「…」になる

### イベント検索

- [ ] キーワード（イベント名・場所）で絞り込める
- [ ] 開催日の範囲（から・まで）で絞り込める
- [ ] 「条件をクリア」で元の一覧に戻る
- [ ] 検索結果からイベント詳細へ遷移→詳細画面の「戻る」リンクが「← イベント検索に戻る」になっている

### イベント詳細（`/events/:id`）

- [ ] 開催日時・場所・定員・残り枠・申込締切・説明が表示される
- [ ] 「申し込む」→申込完了画面へ遷移し、ステータスが「受付済」になっている
- [ ] 受付終了のイベント→申込ボタンが表示されず、注記が出る
- [ ] 既に「受付済」または「キャンセル待ち」のイベントに再度申込→「すでに申し込み済みです」（400）
- [ ] 管理者アカウントでは申込ボタンが表示されず、注記が出る（要件定義書E7）

### マイページ（SC-03）

- [ ] 自分の申込一覧がカード表示され、ステータス（受付済／キャンセル待ち／キャンセル済）バッジが正しい
- [ ] 「キャンセル」→ステータスが「キャンセル済」に変わる
- [ ] キャンセル済み、または開催日時を過ぎた申込は「キャンセル」ボタンが表示されない

### キャンセル待ち機能（機能追加）

- [ ] 定員に達したイベントに申込→エラーにならず「キャンセル待ち」として登録される（201）
- [ ] 申込完了画面に「満席のためキャンセル待ちとして登録されました」の説明が出る
- [ ] イベント詳細・一覧の展開パネルで、満席時は「満席のため、申し込むとキャンセル待ちに登録されます。」の注記と「キャンセル待ちで申し込む」ボタン表記になる
- [ ] マイページで「キャンセル待ち」バッジ（アンバー系）が表示され、「キャンセル」ボタンも押せる
- [ ] 受付済の申込をキャンセル→同じイベントで一番古いキャンセル待ちが自動的に「受付済」に変わる（マイページで確認）
- [ ] キャンセル待ちの申込自体をキャンセル→「キャンセル済」になる（他の人への繰り上げは発生しない）

## 3. 管理者機能

### ダッシュボード（機能追加）

- [ ] 管理者ログイン直後にダッシュボード画面へ自動遷移する
- [ ] 総イベント数・総ユーザー数・受付済の申込数（全イベント合計）が表示される

### イベント管理（SC-04）

- [ ] イベント一覧がカード表示される（イベント名クリックで編集画面へ）
- [ ] 「＋ 新規登録」→フォームの必須項目に赤い「*」が表示される
- [ ] 未入力のまま保存→その場で「〜を入力してください」が表示される（通信前にブロックされる）
- [ ] 新規登録したイベントが一般ユーザー側の一覧にも表示される
- [ ] イベント編集→内容（定員など）を変更して保存できる
- [ ] 削除→一覧から消える
- [ ] 受付済の申込が1件でもあるイベントを削除しようとする→「申込があるため削除できません」（400、削除されない）

### 削除済みイベントの確認・復元（機能追加）

- [ ] イベント管理画面の「削除済みイベント」リンクから削除済み一覧画面へ遷移できる
- [ ] 削除したイベントが削除済み一覧にカード表示される（削除日時つき）
- [ ] 「復元」→一覧から消え、一般ユーザー側・管理者のイベント一覧に再度表示されるようになる
- [ ] 一般ユーザーが`/admin/events/deleted`に直接アクセス→`/events`にリダイレクトされる（E-7）

### 申込状況・実績（SC-05）

- [ ] イベント別の受付済申込数・定員・充足率が表示される
- [ ] 申込数の多い順に並び替えできる（チーム独自機能）
- [ ] 「申込実績CSV出力」→ダウンロードしたCSVが文字化けせず開ける

### ユーザー管理（機能追加、マスタ確認用）

- [ ] 登録済みユーザー（ID・名前・メールアドレス・ロール）の一覧が表示される
- [ ] 新規登録したユーザーがこの一覧にも反映される

## 4. 権限・アクセス制御

- [ ] 一般ユーザーでログイン中に`/admin/**`へ直接アクセス→`/events`にリダイレクトされる
- [ ] 未ログイン状態で`/admin/**`や`/my/applications`へ直接アクセス→`/login`にリダイレクトされる
- [ ] ログアウト後、ブラウザの「戻る」で保護ページに戻れない（リダイレクトされる）

## 5. 見た目・レイアウト（機能追加）

- [ ] ヘッダーが薄紫の単色背景になっている
- [ ] ヘッダーの「ログアウト」ボタンがアンバー色になっている
- [ ] 「申し込む」など最重要のボタンがアンバー色（btn-accent）で目立っている
- [ ] 削除・取消ボタンが赤系の枠になっている
- [ ] ページ背景にうっすらグラデーションが付いている（真っ白一色ではない）
- [ ] イベント一覧・検索・マイページ・管理者のイベント管理が、すべて同じ雰囲気のカード表示で統一されている
- [ ] スマホ幅など狭い画面表示でも大きく崩れない（余裕があれば確認）
