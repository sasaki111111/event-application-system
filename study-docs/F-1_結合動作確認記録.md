# F-1　結合・動作確認　確認記録

実施日：2026-09-15
方法：`http://localhost:4200`（Angular dev server）でブラウザを使い、ログインから一連の操作を連続実行

## 確認観点

1. 画面→API→DBが通しでつながっていること（各操作の結果が次の画面に正しく反映される）
2. SPA要件（技術仕様書§3.2'）：画面遷移がAngular Routerによるクライアントサイド遷移であり、ページ全体の再読み込み（フルリロード）が発生しないこと

## 事前のコードレベル確認

- `frontend/src/app/**/*.html`内の`<a>`タグはすべて`routerLink`／`[routerLink]`を使用しており、素の`href`によるページ遷移は無いことを確認
- `frontend/src/app/**/*.ts`内に`window.location`・`location.href`・`location.reload`の使用が無いことを確認（フルリロードを引き起こすコードが無い）

## 結果

- 上記1〜14を連続して実行し、途中でブラウザの手動リロードを行うことなく、URLの変化に対して画面が白く点滅する等のフルリロードは発生しなかった（Angular Routerによるクライアントサイド遷移のみで完結）ことを目視で確認した。
- 各操作の結果（申込の作成・取消、イベントの作成・編集・削除）が、次の画面表示に即座かつ正しく反映されており、画面→API→DBの一連の流れに問題は無い。
